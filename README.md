# Portal Ford com adequação à LGPD

Versão do portal de lançamento da Ford Ranger adaptada à **Lei Geral de Proteção de Dados (LGPD)**. Desafio do **Ford Enter**.

## O que muda em relação ao portal original

- **Consentimento explícito** no formulário de contato: uma caixa de aceite dos termos, controlada em JavaScript, antes do envio
- Link para a **política de privacidade** junto do aceite
- Vídeo da página de lançamento incorporado pelo **youtube-nocookie**, que evita cookies de rastreamento

## Outras funcionalidades

- Carrossel de imagens
- Comparador de veículos
- Formulário de contato que confirma o envio ao usuário

## Tecnologias

- HTML, CSS e JavaScript puro

## Como abrir

Abra o `index.html` no navegador.
